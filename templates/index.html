❓ Ayuda y referencia de ajustes

⚙️ Servidor general ▾
NAME
Nombre visible del servidor en Content Manager y en la lista de servidores.
PASSWORD
Contraseña para que los jugadores se conecten. Dejar en blanco = sin contraseña.
ADMIN_PASSWORD
Contraseña para comandos de administrador en el juego (/admin) y conexiones RCON.
REGISTER_TO_LOBBY
1 = El servidor aparece en la lista pública mundial de Kunos. 0 = Solo accesible por IP directa.
SUN_ANGLE
Hora del día en grados. 0° = Medianoche, 48° ≈ Mañana, 180° = Mediodía, 320° ≈ Tarde/Noche.
🔌 Puertos y conexión ▾
UDP_PORT / TCP_PORT
Puerto principal para conexiones de juego (predeterminado: 9600). Debe estar abierto en el cortafuegos / router.
HTTP_PORT
Puerto para el endpoint de información HTTP (predeterminado: 8081). Consultado por Content Manager.
PICKUP_MODE_ENABLED
1 = Los jugadores eligen su coche al unirse. 0 = Ranuras fijas asignadas (ej. para eventos de carreras).
LOOP_MODE
1 = El servidor se reinicia automáticamente tras cada sesión (modo Trackday). 0 = Espera reinicio manual.
CLIENT_SEND_INTERVAL_HZ
Frecuencia por segundo con la que el servidor envía datos de posición. Estándar: 18 Hz. Mayor = más fluido pero más carga de red.
🛡️ Ayudas de conducción y reglas ▾
ABS_ALLOWED
Permitir sistema antibloqueo (ABS). Recomendación: 1 para servidores públicos.
TC_ALLOWED
Permitir control de tracción (TC).
STABILITY_ALLOWED
Control de estabilidad electrónico (ESP). Suele desactivarse para servidores realistas.
FUEL_RATE
Consumo de combustible en %. 100 = realista, 0 = infinito, 200 = se vacía el doble de rápido.
DAMAGE_MULTIPLIER
Multiplicador de daño. 0 = sin daño, 100 = realista, >100 = daño incrementado.
ALLOWED_TYRES_OUT
Cuántos neumáticos se permiten fuera de la pista. 2 = Estándar, 4 = todos (sin límite), 0 = estricto.
LEGAL_TYRES
Tipos de neumáticos permitidos como lista separada por comas (ej. "SV,SM"). Vacío = todos permitidos.
📅 Sesiones ▾
PRACTICE TIME
Duración de la sesión de entrenamientos en minutos. 9999 = ilimitado (recomendado para Trackdays).
IS_OPEN
1 = Los jugadores pueden unirse en cualquier momento. 0 = No se permite el acceso tras iniciar la sesión.
RACE LAPS
Número de vueltas de la carrera. 0 = carrera por tiempo (definir TIME).
RACE_OVER_TIME
Segundos tras la llegada a meta del primer piloto hasta que finaliza la sesión. Estándar: 180s.
WAIT_TIME
Tiempo de espera en segundos antes del inicio de carrera tras terminar la clasificación.
🌤️ Clima y pista ▾
GRÁFICOS (Clima)
Ajusta el preset visual de clima. Presets: 3_clear (soleado), 2_light_clouds (nubes dispersas), 7_heavy_clouds (nublado), 8_drizzle (llovizna), 11_practice_storm (tormenta).
BASE_TEMPERATURE_AMBIENT
Temperatura del aire en °C. Afecta a la temperatura del motor y comportamiento de neumáticos.
BASE_TEMPERATURE_ROAD
Temperatura del asfalto en °C. Más cálido = más agarre en slicks, más frío = menos agarre.
SESSION_START (Pista dinámica)
Nivel inicial de agarre en %. 95 = casi ideal, 80 = pista verde. Aumenta con las vueltas.
LAP_GAIN
Cuánto agarre se gana por cada vuelta completada. 132 = estándar de Nordschleife.
🔧 AssettoServer (extra_cfg.yml) ▾
EnableServerDetails
Debe estar activo para que la descripción, logo y detalles aparezcan en Content Manager.
EnableAntiAfk
Los jugadores que estén ausentes (AFK) demasiado tiempo serán expulsados automáticamente.
MaxPing
Ping máximo en ms antes de expulsar a un jugador automáticamente. Estándar: 500ms.
EnableWeatherFx
Activa CSP WeatherFX para lluvia y transiciones climáticas fluidas. Requiere CSP 0.1.76+.
MinimumCSPVersion
Versión mínima de CSP requerida para unirse (0 = sin límite). Ejemplo: 2144 para CSP 0.1.77.
RconPort
Puerto para conexiones RCON. Estándar: 9700. Usado por el panel para expulsar, banear y chatear.
📜 Comandos RCON ▾

Los comandos RCON se pueden escribir en la pestaña Registros. La contraseña de admin de server_cfg.ini se usa automáticamente.

/say <text>
Enviar mensaje a todos los jugadores (aparece en el chat del juego).
/kick_id <id>
Expulsar al jugador por su ID de ranura (ID visible en la pestaña Pilotos).
/ban_id <id>
Banear y expulsar a un jugador.
/next_session
Saltar a la siguiente sesión.
/restart_session
Reiniciar la sesión actual.
/set_ballast <id> <kg>
Añadir lastre a un jugador en tiempo real.

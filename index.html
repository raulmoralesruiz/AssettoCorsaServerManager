❓ Ayuda y referencia de ajustes

⚙️ Servidor general ▾
NAME
Nombre que se muestra del servidor en Content Manager y en la lista de servidores.
PASSWORD
Contraseña para los jugadores al unirse. Dejar vacío = sin contraseña.
ADMIN_PASSWORD
Contraseña para comandos de administrador en el juego (/admin) y para conexiones RCON.
REGISTER_TO_LOBBY
1 = el servidor aparece en la lista pública de servidores de Kunos a nivel mundial. 0 = solo accesible por IP directa.
SUN_ANGLE
Hora del día en grados. 0° = medianoche, 48° ≈ mañana, 180° = mediodía, 320° ≈ tarde.
🔌 Puertos y conexión ▾
UDP_PORT / TCP_PORT
Puerto principal para las conexiones del juego (predeterminado: 9600). Debe estar abierto en el firewall / reenvío de puertos del router.
HTTP_PORT
Puerto para el punto de información HTTP (predeterminado: 8081). Content Manager lo consulta para los detalles del servidor.
PICKUP_MODE_ENABLED
1 = los jugadores eligen su propio auto al unirse. 0 = slots asignados (p. ej. para eventos de carrera).
LOOP_MODE
1 = el servidor se reinicia automáticamente después de cada sesión (modo Trackday). 0 = el servidor espera un reinicio manual.
CLIENT_SEND_INTERVAL_HZ
Con qué frecuencia por segundo el servidor envía datos de posición. Predeterminado: 18 Hz. Más alto = más fluido, pero más carga de red.
🛡️ Ayudas de conducción y reglas ▾
ABS_ALLOWED
Permitir el sistema antibloqueo (ABS). Recomendación: 1 para servidores públicos.
TC_ALLOWED
Permitir el control de tracción.
STABILITY_ALLOWED
Programa electrónico de estabilidad (ESP). En servidores realistas suele estar desactivado.
FUEL_RATE
Consumo de combustible en %. 100 = realista, 0 = infinito, 200 = se vacía el doble de rápido.
DAMAGE_MULTIPLIER
Tasa de daño. 0 = sin daño, 100 = realista, >100 = daño aumentado.
ALLOWED_TYRES_OUT
Cuántos neumáticos fuera de la pista se permiten. 2 = predeterminado, 4 = todos (sin límite), 0 = estricto.
LEGAL_TYRES
Tipos de neumáticos permitidos como lista separada por comas (p. ej. "SV,SM"). Vacío = todos los neumáticos permitidos.
📅 Sesiones ▾
TIEMPO DE PRÁCTICA
Duración de la sesión de práctica en minutos. 9999 = ilimitado (recomendado para Trackdays).
IS_OPEN
1 = los jugadores pueden unirse en cualquier momento. 0 = no se permite unirse después del inicio de la sesión.
VUELTAS DE CARRERA
Número de vueltas para la carrera. 0 = carrera basada en tiempo (luego configurar TIME).
RACE_OVER_TIME
Segundos después de la meta del primer piloto hasta que termina la sesión. Predeterminado: 180 s.
WAIT_TIME
Tiempo de espera en segundos antes del inicio de la carrera tras el final del qualifying.
🌤️ Clima y pista ▾
GRÁFICOS (Clima)
Configura el preset visual de clima. Presets: 3_clear (soleado), 2_light_clouds (poco nublado), 7_heavy_clouds (muy nublado), 8_drizzle (llovizna), 11_practice_storm (tormenta).
BASE_TEMPERATURE_AMBIENT
Temperatura del aire en °C. Influye en la temperatura del motor y el comportamiento de los neumáticos.
BASE_TEMPERATURE_ROAD
Temperatura de pista en °C. Más calor = más agarre con slicks, más frío = menos.
INICIO DE SESIÓN (Pista dinámica)
Nivel inicial de agarre en %. 95 = casi ideal, 80 = pista verde. Aumenta con las vueltas.
LAP_GAIN
Cuánto aumenta el agarre por vuelta. 132 = valor predeterminado de Nordschleife.
🔧 AssettoServer (extra_cfg.yml) ▾
EnableServerDetails
Debe estar activado para que la descripción, el logo y los detalles aparezcan en Content Manager.
EnableAntiAfk
Los jugadores que permanecen AFK demasiado tiempo son expulsados automáticamente.
MaxPing
Ping máximo en ms antes de que un jugador sea expulsado automáticamente. Predeterminado: 500 ms.
EnableWeatherFx
Activa CSP WeatherFX para lluvia y transiciones de clima fluidas. Requiere CSP 0.1.76+.
MinimumCSPVersion
Versión mínima de CSP para unirse (0 = sin límite). Ejemplo: 2144 para CSP 0.1.77.
RconPort
Puerto para conexiones RCON. Predeterminado: 9700. También lo usa el panel para expulsión/bloqueo/chat.
📜 Comandos RCON ▾

Los comandos RCON se pueden escribir en la pestaña de registros. La contraseña de administrador de server_cfg.ini se usa automáticamente.

/say <text>
Enviar un mensaje a todos los jugadores (aparece en el chat del juego).
/kick_id <id>
Expulsar jugador por ID de slot (ID visible en la pestaña de pilotos).
/ban_id <id>
Bloquear y expulsar jugador.
/next_session
Saltar a la siguiente sesión.
/restart_session
Reiniciar la sesión actual.
/set_ballast <id> <kg>
Configurar lastre de un jugador en vivo.
